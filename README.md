# Overview
This is a console-based Pokemon card battle game written in Kotlin. The game creates and shuffles a deck and deals cards to the players. Players take turns choosing cards while following the leading type when possible. Pokemon type and HP determine the winner of each turn. Players earn points for winning turns, and the player with the highest final score wins.

The purpose of creating this software was to learn the basics of Kotlin and practice using a new programming language.

# Development Environment

I used IntelliJ IDEA to develop and test the project and Git/GitHub for version control. I used JDK 21 to run the project.

The game is written in Kotlin. I also used Kotlin's standard library for working with collections, files, and user input.
